# Retrospective DOC interpolation comparison

The fixed environmental MLP + GRU + graph Transformer is compared with seasonal medians, nearest same-month observation, Euclidean and NHD river-distance IDW, bounded spatiotemporal IDW, exponential ordinary kriging, and exponential spatiotemporal ordinary kriging. Linear and PCHIP time interpolation additionally participate in the temporal track. This is internal Mississippi development evidence, preserving existing paper freezes and joint native/log1p MAE endpoints.

Temporal tasks use 266 eligible stations selected from observation dates alone. Each seed 42/43/44 selects one validation and one test three-month core per station, separated by at least 24 months. The 3/6/12-month gaps have the **same core query cells within a seed**; additional surrounding observations are hidden but not scored. Eligibility requires largest-gap brackets within twelve months outside both gaps and at least six retained training observations. All remaining observed DOC is shared supervision/support. This excludes unbracketed sparse stations rather than pretending their unknown DOC has truth. Nine new fusion fits use the unchanged architecture, log1p loss, AdamW, maximum60 epochs, minimum15 and patience10. Time interpolation may use observations before and after the gap: this is retrospective smoothing, not forecasting. The fusion model learns from the same visible training labels but does not read DOC context as an input.

Spatial tasks retain the five previously inspected HUC4 whole-station masks and 7,262 queries at 104 stations. Fusion predictions reuse the audited parent models. Every interpolator is fitted on the source **train** cells only: validation DOC is used solely to select predefined settings, and target DOC never becomes a neighbour. Native station time interpolation is ineligible for zero-DOC stations and is not included in the spatial table.

All 14 task selections and nine neural checkpoints must be complete and hash-frozen before new target scoring begins. IDW neighbour count/power, bounded space-time scales, and kriging range/nugget have small predefined grids selected by validation native MAE, log1p MAE, then identifier. Same-month ordinary kriging requires at least three donors and uses up to30 nearby stations. Space-time kriging uses up to20 observations within the declared 6/12-month window. Its exponential covariance uses the Euclidean norm of scaled Earth-centered chord coordinates and time, with a positive nugget. River IDW uses cached physical mainstem/shared-downstream distances; these are not inferred travel times.

Missing raw interpolation predictions receive an explicitly recorded training-only fallback: station/calendar-month median, station median, source/calendar-month median, global median. Thus full-population tables compare **complete operational methods, including fallback**. They must display intrinsic interpolation coverage beside MAE/log1p MAE/RMSE/predictive R². Additional tables compare raw interpolation and fusion on the exact common covered query subset. Partial-coverage errors cannot silently enter a full-population leaderboard. Concentrations clamp to the inherited [0,expm1(15)] range; raw outputs remain in saved predictions.

Metrics are calculated independently for each seed/mask then averaged, without prediction ensembling. Spatial deterministic methods repeat across nominal seeds but are not independent fits. Temporal query counts differ between seeds, and gap lengths share query cells, so they are not independent experimental replicates. No population uncertainty or superiority significance is claimed from seed repetition alone. Evaluation covers observed hidden cells only, not a full continuous river field.

Source snapshots, masks, original dispatcher hash, dataset/nodes/geometry hashes, parent prediction hashes, dirty-tree/commit provenance, checkpoints, trace and prediction sidecars are frozen under `experiments/phase4_transfer/doc_interpolation_v2/`. Training enters through an isolated versioned `scripts/run_ladder.py`; the original dispatcher is untouched. Audits replay every candidate validation output and selected target output, check support/query separation, verify raw/fallback coverage, independently recompute full and common-subset metrics, and rerun historical K-shot contracts and the full test suite.
