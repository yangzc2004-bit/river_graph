# 一页结论与局限（2026-09-12）

## 可以说的

1. **图结构对稀疏 DOC 重建有帮助，但增益不逐级单调。** 在 8 个 key mask 上，H2X 的平均 MAE 最低（E1 1.390 / E2a 1.002 / E2b 0.946 / E3 1.802 mg/L，均为 5 训练种子均值）。
2. **H2X 相对 H2 的 MAE 改善在 E2a、E2b、E3 上稳定**：同 seed、同 mask 配对差值 5/5、5/5、15/15 全为负。
3. **`e2b_partial` 平均 R² = 0.447**（H2X，5 训练种子，种子 sd 0.033），是四个场景中最高。
4. **H2X 训练更稳定**：E2b 的 MAE 种子 sd 为 0.026，而 H2 为 0.151。
5. **误差由极端值主导**：154 次历史预测中，真实 DOC 最高 1% 的单元贡献平方误差的中位数为 74.2%（E3 seed43 达 95.6%）。因此 log 空间指标必须与 mg/L 指标并列报告。
6. **区域结论**：E3 下 HUC2=10（Missouri）误差最高（H2X 逐单元加权 MAE 2.656，106 站）；但 HUC2=8（Lower Mississippi，仅 4 个 test 站）**顺序反转**（基線 0.610 反而最好、H2X 2.180 最差）——**H2X 的优势不是全区域一致**。
7. **历史结果可被追责**：冻结表 154 行的逐样本预测现已全部有来源，并可通过 `scripts/audit_artifacts.py --verify` 独立复算。

## 不能说的

1. **不能说 H2X 在 E1 提高了 R²**：H2 = 0.439613、H2X = 0.437845，配对差值均值 −0.0018（E1 的 MAE 也只有 11/15 对更优）。
2. **不能说 transport 门控改善了未来重建或空间外推**：H2 对 H1 的优势只在 E1 稳定（15/15）；E2a/E2b 配对均值 ≈0（0.002 / −0.004）且区间很宽，E3 为 9/15。
3. **不能把 H2X 的增益归因给编码器**：H2X 同时增加生态信息与编码器，缺少同协议 H2E 对照。
4. **不能说图模型对源头站失效**：无上游监测邻居的站点误差更高，但站点均值基线上顺序相同，主要反映站点难度。
5. **不能把 ST 与其他类型的差异当作 ST-only 训练验证**：模型在混合数据上训练，基线上也有同样的顺序。
6. **不能断言 06438000 高值的成因**：土地利用、采样方法都只是相关性猜测，现有审计未能用可用协变量解释。同时注意该站分布高度右偏（28 个观测月，中位数 6.75、均值 58.2、最大 460 mg/L），**不能把逐模型 `mean_true` 的再聚合当作观测统计**。
7. **不能主张统计显著性**：每模型仅 5 次训练、E2a/E2b 仅 1 个 mask、8 个 mask 共享同一批观测单元，不满足独立样本假设。本阶段只给描述性区间与配对计数。
8. **不能说逐级机制消融已完成**：H1→H2→H2X 每一步都同时改动了不止一件事，`env_groups` 取列错误也尚未修复。
9. **不能说 H2X 在每个区域都更优**：HUC2=10 上它确实最好，但 HUC2=8（4 站）上基线最好而 H2X 最差；整体均值不等于每个区域都成立。

## 一句话结论

**本轮把「哪些数字可以信、哪些不能信」讲清楚了：H2X 在平均 MAE 与未来重建上确有优势，但 E1 的 R² 没有提高、transport 门控的相对 H1 增益并不稳定，而机制归因、跨流域泛化与五种子逐样本分析都还没有完成——这些缺口已逐条列出，没有用推断或重训去补。**
