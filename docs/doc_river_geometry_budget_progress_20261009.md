# River geometry and DOC export progress

The linked geometry and carbon-budget investigation is complete in
`experiments/phase4_transfer/doc_river_geometry_budget_v1/`.

Real path differences, source arrival alignment, shared downstream spreading
and explicit processing are connected to concentration peak, timing, width and
integrated additional carbon. Water and carbon flux are routed separately.
The 3,872 scenarios use 121 real tributary pairs feeding 38 receivers in 17
connected systems. Geometry and imposed process assumptions remain distinct.

The three existing hourly outlet archives support 161 complete flow-selected
event records, including nonpositive DOC responses, and 322 nested window
budgets. All 128 previously resolved positive responses have complete budgets.
One other Kervidy event misses an hourly pair; it is not filled.

The main result is that conservative path/spreading changes can reduce and
widen concentration peaks without removing additional carbon. Explicit pulse
processing reduces total additional carbon. In measurements, DOC concentration
peak timing and carbon-flux peak timing differ, and peak height alone does not
reliably rank event export. A bounded outlet export is not a net river removal
measurement.

The next morphology test should combine simultaneous branch/receiver DOC and
flow with rooted channel geometry and lateral-input accounting. Outlet-only
records do not isolate shared-channel processing from incoming carbon changes.
Keep the focus on pathway diversity, junction layout and shared-route dynamics.
No model training or automatic monitoring is restarted.
