# Figures

- `fig1a_station_map.png` — MRB DOC monitoring stations (571), colored by
  graph component (largest component / other components / isolated), over
  the hydrographic network. AI-rendered illustration based on the real
  graph statistics.
- `fig1b_station_graph.png` — abstract station graph, 571 stations / 562
  directed edges (upstream → downstream). AI-rendered illustration.

Note: these two are presentational renderings, not direct pipeline output.
The pipeline-generated equivalent is produced by `scripts/build_graph.py`
at `data/processed/mississippi_graph.png` (not versioned; `data/` is
gitignored).
