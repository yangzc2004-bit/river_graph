## 1. 本次调整的决定

本轮目标是完成来源清楚、口径一致、明确局限的阶段报告。现有证据不能回答的问题列为后续验证需求，不为补齐图表启动训练。

执行顺序调整为：**核验已有产物 → 完善后续保存逻辑 → 分析已有指标与可用预测 → 校准图表和报告 → 列出后续实验。**

- 不执行 `run_freeze.py`，不启动模型重训，也不为估时跑完整训练。
- 不改写当前数据集和 mask。站点规则核验、现有模型的分组分析可以做，清理后的独立训练版本留到后续。
- 缺失历史预测优先从明确的 Git 对象或备份恢复；找不到就标缺失，不能从指标反推逐样本预测。
- 修复代码不等于修复旧结果。受分组取列错误影响的旧消融不进入机制结论。
- 工程验证使用合成数据、mock 和已有预测复算，不调用真实模型训练。

本版替换上一版“清数据、重建图、重训对照，再分析”的近期安排；这些研究需求保留在 B 阶段。
