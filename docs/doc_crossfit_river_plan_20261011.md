Prospectively fixed on 2026-10-11 before fitting or reading the new validation/test predictions. This is a new controlled experiment, not an exact retraining of the historical ecological/retrieval/observed-DOC correction chain. The user's chosen split family is the river-correction branch: partitions 142/143/144, model seeds 42/43/44. Dataset and original train/validation/test cell lists are copied byte-for-byte. No paper endpoint or released default changes.

## Question and factorial design

Compare correction learning from **fitted** local anchors with learning from **whole-source-station-fold-held-out** anchors. Each strategy trains three equal-capacity attention corrections: genuine bidirectional river paths; generic attention without direction/path features; matched donors having no upstream or downstream connection. A fresh shared local ecological + temporal baseline is essential because the historical retained encoders already saw source labels; substituting tree-only OOF predictions would not remove that exposure.

The local predictor combines covariate-only ExtraTrees (200 trees, leaf 4, log1p target) with an ecological MLP (15 to 24) and causal 12-month GRU (14 to 32), followed by a log correction. Inputs retain the existing monthly temperature/discharge, visibility, calendar, coordinates, 13 regime columns and eight daily-flow descriptors. No DOC-valued inputs, chemistry, station embeddings or legacy supervised weights are used. Fixed 30 epochs, Adam 0.001, native MAE with source-Q90 weight 2 and a local delta penalty 0.001. All six supervised local components (full source plus five source-station folds) are trained from fresh identical seeded initialization. Receiving-fold labels enter neither trees, supervised encoders, target statistics nor epoch choice. Label-free preprocessing is fixed from source covariates, retaining the old known-atlas static statistics.

The fitted arm uses the full-source local predictor to learn source errors. The crossfit arm uses five fully retrained local models, each excluding the receiving station fold. At validation/test inference **all six corrections use exactly the same full-source local model**. This tests the correction training distribution, not an OOF ensemble deployment. Correction heads have identical initial tensors, parameter count, learning rate, batch permutations, epoch count and label weights. The local baseline also appears as a seventh diagnostic row.

## Relationship controls

Ten nearest mapped upstream and ten downstream donors within 3000 km, found through the entire known station atlas. Missing intermediate observations do not remove physical paths. Each receiving source fold (or whole held-out role) is excluded from every donor pool. Donor states contain environmental encoding/covariates only; there is no observed-DOC library. States at lags 0/1/3 are valid when measured hydro/daily coverage exists in their preceding 12-month window.

Generic attention replaces each path slot with a donor matched by drainage area and label-free availability from the entire eligible pool; its path features are zero, and its weights remain learned. It is a capacity/candidate-matched generic sparse attention control, not uniform averaging or all-357-node dense attention. The nonconnected control excludes all mapped ancestors, descendants (including paths beyond 3000 km) and receiver COMID aliases, then matches donors on the same attributes. It keeps the real slot's pseudo-path features to isolate donor identity/connectivity. It does not claim that the pseudo paths are real rivers. Use the intersection of all three candidate-date availability masks for **identical support and candidate counts**. Same model receives 83-dimensional environmental states, 84-dimensional query and 36-dimensional candidate features; two heads of width 32. Zero-support cells reproduce the local baseline exactly.
