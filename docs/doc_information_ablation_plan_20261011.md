# Matched DOC information ablation

Date: 2026-10-11. The fixed environmental MLP, GRU and dense graph Transformer are evaluated after removing their information packages, using exactly the masks of the completed comparator study. The primary question is the conditional contribution of each package to observed-query retrospective DOC reconstruction. Architecture-family optimality and environmental causal effects are separate questions.

The main spatial experiment retains the five HUC4 source/validation/target tasks, three seeds and 7,262 queries at 104 stations. Seven arms are fixed before any new target scoring: full model; no environment; no time; strict no river; self-only no messages; current-only; and generic dense attention without river relation categories. The three primary removals are also repeated on all nine frozen 3/6/12-month temporal tasks. Those use 266 eligible stations and identical three-month scored cores within each masking seed.

All arms retain identical parameter tensors, seed initialization, hidden widths, optimizer, month permutations, observed-cell weights and early-stopping rule. Inputs are zeroed after common source-only scaling; bias/constant representations remain. Self-only attention retains projections, normalization, residuals and feed-forward paths. Training uses the source station-induced graph and source DOC labels only; validation and test graph context use permitted exogenous covariates. No DOC context or station embeddings enter the model. Native MAE and log1p MAE remain the joint primary endpoints; RMSE, predictive R² and bias are secondary. Increases relative to the full-model error describe performance loss under each conditional removal.

The static package has 15 columns: four river descriptors (stream order, log drainage area, slope and monitoring-graph headwater), nine ecological/climate descriptors and two generic coordinates. No-environment removes all fifteen, retaining graph relations. No-time removes all twelve eight-channel driver steps, masks, ages and seasonal encodings, including the separate seasonal pair. Strict no-river removes the four explicit static river descriptors and all cross-node exchange. Remaining ecological/climate attributes and coordinates are retained. These packages overlap; their contributions cannot be added to 100% or interpreted as independent environmental causes.

Three spatial controls resolve specific ambiguities. No-messages retains all static features, isolating cross-node exchange conditional on the descriptors. Current-only retains the same GRU and twelve-step shape, zeros the eleven past steps and current observation-age channels, and retains current values, masks and season; it distinguishes past information from removal of every dynamic driver. No-relations keeps dense attention and static descriptors, replacing upstream/downstream/ancestor categories with generic self/unconnected categories; it isolates relation coding conditional on dense context. Merely emptying graph edges would not stop the existing dense attention, so strict no-river explicitly changes the attention neighbourhood to self-only.

There are 102 new fits: 75 spatial and 27 temporal. The full spatial model and self-only control reuse 30 individually audited parent checkpoints; nine temporal full-model checkpoints are reused from the interpolation study. Original four-thread spatial and one-thread temporal arithmetic are retained. All 141 validation checkpoints/receipts must be frozen before any new target scoring. Every prediction receives config/code/dataset/mask provenance. New products are isolated in `experiments/phase4_transfer/doc_information_ablation_v1/`; existing paper endpoints and artifacts are unchanged.

Verification replays all 141 validation and test checkpoints, checks actual removed channels and self paths, source-only normalization, target truth, masks, parameter counts, validation epoch selection, full coverage and summary arithmetic. Spatial paired uncertainty uses the previously specified 5,000 whole-region bootstrap draws after seed-error averaging, with five clusters; intervals are exploratory and unadjusted. Temporal seed repetition alone does not establish population significance. Historical K-shot contract tests and the full suite are rerun after the new freeze.

The study uses previously inspected Mississippi development tasks. It does not validate independent rivers, naturally missing DOC cells, arbitrary virtual sites or an entirely observed continuous river field. Any adverse ablation result remains in the output; neither endpoint nor model configuration is changed after observing test results.
