# Matched directed river relation optimization

Date: 2026-10-11. This is a prospective internal Mississippi development comparison following the information ablation. The previous explicit relation categories produced only a 0.04% spatial native-MAE difference from generic dense attention. The question is whether better use of known directed topology improves reconstruction with the same covariates, cohort, masks, neural capacity and optimization rules.

Four candidates are fixed before target scoring:

| Recipe | Directed mechanism | Question |
| --- | --- | --- |
| Path closure | Compute reachability on the complete known station graph, then restrict feature exchange to permitted-role nodes | Were paths lost when intermediate stations were omitted from an induced training/inference graph? |
| Upstream only | Closure plus self/upstream-ancestor attention in every head | Does enforcing the upstream-to-downstream direction improve reconstruction? |
| Direction heads | Closure plus separate upstream/self, downstream/self and global heads | Does separating information roles work better than forcing every head to mix them? |
| Directed path bias | Closure plus a six-component linear bias basis: self, upstream, downstream, unrelated, upstream log-hop distance, downstream log-hop distance | Does continuous directed graph distance help beyond coarse relation categories? |

The original induced-graph six-category Transformer is the unchanged reference. Generic self/other dense attention is an additional control; its spatial checkpoints are reused from the completed ablation, and its temporal checkpoints are fitted here. The environmental MLP, twelve-step GRU, separate season encoding, two spatial blocks, three heads, widths, dropout and readout remain identical. All six recipes have exactly 12,565 parameters and exactly matching seeded parameter tensors. The path basis reuses the six-by-three bias weight tensor rather than adding capacity.

Distance is shortest **station-edge count** on the existing 357-station directed graph, encoded as log1p(hops)/log(2) clipped at eight. It is not river kilometres, hydraulic travel time or a DOC flux law. Existing edge attributes include target-reach length, which is not the total station-to-station river-path length; those are not substituted for physical path distance. No new external environmental data are introduced. Complete topology supplies only connectivity through excluded intermediate nodes; their feature vectors, hidden states and DOC labels do not enter the active graph. All queries and keys remain restricted to the original permitted roles.

All recipes run on the same five whole-station HUC4 tasks (1013, 1019, 0708, 1030, 1101), seeds 42/43/44 and 7,262 observed hidden queries at 104 stations, plus all nine original 3/6/12-month temporal masks at 266 eligible stations. Temporal masks retain identical three-month scored cores within seed. These remain retrospective observed-query reconstructions. Source-only scaling and DOC supervision, source-only training graphs and source+validation/target exogenous inference context are unchanged. Four-thread spatial and one-thread temporal arithmetic are retained. AdamW, loss, label weights, shuffled month panels and native-MAE validation stopping are copied exactly from the original runner.

There are 144 selection packages: 105 new fits (60 spatial, 45 temporal) and 39 reused audited checkpoints (24 original baselines and 15 spatial generic controls). All selections are bound before new target scoring. A single global recipe is chosen prospectively from the original baseline plus four candidates using validation only: average relative native/log1p MAE with equal endpoint weights, equal task weights within each track, and equal space/time track weights. The original baseline may win. Generic dense is a diagnostic control. This choice and its hash are bound before target scoring; the lowest test-table row is not retroactively the validation-selected recommendation.

Native MAE and log1p MAE remain joint primary endpoints; RMSE, predictive R² and bias are secondary. Positive improvement percentages use the original baseline as denominator. Every candidate and control is reported, including adverse results and metric tradeoffs. Spatial uncertainty reuses 5,000 paired five-HUC4 cluster bootstrap draws after averaging seed errors. These are exploratory, unadjusted intervals on previously inspected development regions, not an independent confirmatory test. No temporal population significance is inferred from three masking seeds or repeated cores.

Verification checks functional directionality, no downstream/unconnected influence for the upstream-only operator, missing-intermediate paths, distance orientation, finite gradients, identical initialized tensors and the original optimizer loop. After training, every validation/test prediction is replayed; query truth, masks, source normalizations, selected epochs and metrics are independently checked. SciPy shortest paths independently verify the full-topology distances and relation matrices. The validation-only global choice, reference baseline agreement and paired intervals are independently reconstructed. A fresh protocol/manifest and isolated run_ladder runtime preserve code/dataset/mask/checkpoint hashes. Existing paper freezes and endpoints are unchanged.

Design motivation comes from structural attention bias in [Graphormer](https://arxiv.org/abs/2106.05234), whose spatial encoding uses shortest paths, and upstream hydrological priors in [HydroNets](https://arxiv.org/abs/2007.00595). These are locally designed DOC candidates, not reproductions of either complete published model. Prior evidence: [information ablation](doc_information_ablation_results_20261011.md). Independent rivers, true missing-cell accuracy, arbitrary virtual sites and physical transport consistency remain separate questions.
