# RiverDOCNet dynamic reconstruction experiment

This prospective development experiment retains the environment MLP, twelve-month GRU and upstream/downstream/global graph Transformer. It tests whether richer hydrological variability descriptors or a concentration/change objective improve temporal reconstruction. Existing paper protocols, primary endpoints and historical predictions remain unchanged.

The four matched neural recipes are original monthly inputs with standardized log DOC MSE, added daily-flow descriptors with the original loss, original inputs with joint level/change loss, and both additions. All use the same 12,853 parameters and seeded initial tensors: the original-input controls zero the eight extra GRU channels. The MLP, GRU hidden width, spatial heads, optimizer and stopping rule are retained. All arms use identical shuffled current-month anchors and compute previous-month states; previous labels contribute only when both months belong to the training role. The joint objective adds native concentration MSE and adjacent-month change MSE, each with coefficient 0.25 and training-only scale.

Eight previously frozen daily-discharge descriptors quantify within-month spread, flashiness, rising fraction and availability. They require no DOC and no future month; their monitoring footprint is unchanged. This study enriches hydrological information and does not fill naturally missing hydrology or introduce global meteorological forcing. Monthly means are means of available samples, not continuously measured monthly concentration. All 22,571 frozen labels are retained, including raw high-DOC records.

The five existing HUC4 whole-station splits use three optimization seeds. All nine existing 3/6/12-month temporal masks are also reused, including their fixed scored three-month cores. There are 96 new neural fits and 96 tree fit groups. History-aware random forest and XGBoost use the same local input packages, with the three existing native/log recipe choices per family selected solely by source validation. This adds strong regression comparisons to temporal gaps as well as geographical gaps.

Native MAE and log-MAE remain joint primary endpoints; RMSE and predictive R-squared are secondary. Newly declared supplementary diagnostics are within-station centered native/log R-squared, within-station standard-deviation ratio, consecutive-month change error and correlation. These assess observed temporal fluctuations and do not constitute validation of naturally missing cells or arbitrary river locations. The global neural recipe is chosen using the existing equal-endpoint, equal-task, equal-space/time validation relative-error rule; test results do not change that choice.

The dataset, daily product, masks, runtime and source-validation selections are frozen. Training enters through an isolated version of run_ladder. Every prediction has a provenance sidecar. Independent verification checks original truth, identical queries, preprocessing, chosen checkpoints, all prediction replays and metric/selection calculations. Previously examined development regions and overlapping query cores remain development evidence rather than independent confirmation.
