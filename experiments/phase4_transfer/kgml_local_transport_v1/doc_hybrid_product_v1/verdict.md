# DOC hybrid model result

Five independent seeds (42--46) were used for the validation-selected DOC
product.  The spatial families use the validation-selected ExtraTrees context
expert.  The two temporal families use a log-space affine stack of the
ExtraTrees context prediction and the ExtraTrees residual KGML prediction.
The affine coefficients are fit on validation predictions only and then held
fixed for the terminal test view.

## Terminal performance

| Missingness family | Hybrid seed mean MAE | Median seed ensemble MAE | ExtraTrees context seed mean MAE |
|---|---:|---:|---:|
| E1 (random spatial cells) | 1.4362 | 1.4340 | 1.4362 |
| E2a (strict temporal holdout) | 0.8871 | 0.8840 | 1.0475 |
| E2b (partial temporal holdout) | 0.7838 | 0.7829 | 1.0165 |
| E3 (spatial station holdout) | 2.5453 | 2.5372 | 2.5453 |

Across all 11,046 terminal cells per seed, the median seed ensemble has MAE
**1.4713**.  The corresponding ExtraTrees context ensemble is **1.5445**;
the improvement is **4.7%**.  The old default RF-context baseline is **1.5935**
on the same five seed/mask evaluation, so the improvement is **7.7%**.

The strongest gain is in temporal extrapolation: the affine graph-residual
stack reduces E2a error by about 15% and E2b error by about 23% relative to
the selected ExtraTrees context model.  Spatial station extrapolation remains
the limiting family; the product is still useful there because the tuned
ExtraTrees context model is consistently better than the old RF.

## Interpretation

The result supports a hybrid architecture: explicit ecological and temporal
context supplies the stable base prediction, while the trained residual branch
adds a complementary correction when target observations are withheld in
time.  The graph residual is currently the `no-message` residual arm because
the upstream message ablation did not add a reproducible gain in this data
regime.  This is a performance model result, not evidence that river topology
is unnecessary in general.

All terminal metrics are generated by `build_doc_hybrid_product.py`; the
affine coefficients and per-seed selection are recorded in
`extra_trees_affine_v1/seed_family_metrics.csv`.
