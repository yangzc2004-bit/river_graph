# Next: connected-path tests of mixing and buffering

## Aim
Move from structural association to observations along real upstream–downstream
paths. Keep the current released DOC model fixed. Do not select path groups by
model error or DOC concentrations.

## Path population
Start with the existing 324 physically resolved station links, source-permitted
DOC readings and the 141 fixed-edge seasonal-anomaly subset. Save eligibility
at every lag and separate <=50, 50–200 and >200 km paths. These are observational
path studies; source, receiver and intermediate reaches can be shared.

## 1. Mixing at confluences
Contrast paths entering a major receiving confluence against same-order paths
with few major confluences. Retain continuous incoming-area balance and count
observed branches. Where two tributaries and a receiver are observed in the
same month, compare the receiver with both sources; never treat one measured
tributary as the complete upstream mixture. Area weights are an explicit proxy
sensitivity, not measured tributary discharge weights.

## 2. Integration and storage
For each eligible source–receiver pair, estimate seasonal amplitude change,
seasonal-anomaly covariance and concentration–flow response change. Compare
storage-exposed and unexposed paths matched on distance, order, ecology and
sampling. Classify storage exposure by actual path attributes, not merely the
receiver's neighbourhood profile. Distinguish weaker amplitude from lower mean
concentration; a reservoir need not reduce bulk DOC.

## 3. Timing and common forcing
Keep 0/1/3/6/12 monthly lags, with a common-pair sensitivity. Adjust local month,
temperature and flow anomalies before attributing upstream residual covariance
to connectivity. Use matched non-connected pairs as a similarity/common-forcing
comparison. Match observation completeness; avoid the support mismatch seen in
the earlier rewired residual pilot.

## Outputs and model implication
Produce connected-path response figures, matched comparison tables and regional
stability checks. Estimate uncertainty with shared-station or basin blocks,
rather than treating the 141 links as independent replicates.
Confluence evidence informs a mixing operator; integration informs short-range
messages; storage evidence informs memory/attenuation. Then return to the fixed
local model plus sparse river residual, with one mechanism changed at a time.
