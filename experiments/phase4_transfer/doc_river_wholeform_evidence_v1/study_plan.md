# Whole-network form and DOC: evidence consolidation and independent-data audit

Date: 2026-10-09

## Question

Has the project established an observed DOC difference between elongated,
mainstem-dominated and broad tributary-rich river networks? Separate this from
the additional predictive information in continuous branching/path descriptors
and from effects of geometry in controlled routing simulations.

The previous morphology, routing, monthly transport, outlet-event and local
confluence results have already been seen. This version synthesizes those
results; it is not a new confirmation using the same observations.

## Work in this version

   populations, endpoints or estimates. Extract the direct class comparison,
   the continuous information-block comparisons and their sampling units.
2. Record which field archives have complete whole-network geometry, measured
   DOC and flow, independent networks, and simultaneous branch/receiver records.
   Distinguish local channel geometry from the whole upstream network.
3. Inspect the public, separately published NEON ultraviolet-absorbance dataset

   fields. If public files are accessible, profile their actual observations.
   This is a potential independent laboratory-DOC replication source, not a
   sensor-DOC or storm-routing result. Do not convert fDOM directly into DOC.
   NEON's original API requires a user token; do not seek credentials or bypass
   that requirement. A legitimately public derived archive retains its own
   authority limits and cannot substitute for unprovided original quality flags.
4. Close the current-data inference and specify a bounded field validation that
   answers the original shape question. Do not continue adding simulations to
   manufacture observational support.

## Future field comparison

Two distinct questions need distinct observations:

- **Independent concentration/variability replication:** actual whole-network
  geometry and laboratory DOC across independent rivers, with comparable basin
  scale, hydroclimate, land cover and sampling calendars. Analyze continuous
  geometry alongside the existing class definitions. Keep all eligible rivers.
- **Dynamic mechanism attribution:** repeated incoming branch and receiving
  DOC/discharge curves, actual directed paths, and arrival/residence information.
  First explain the receiving response from measured incoming waves and water
  amounts; then test the additional information in path dispersion, confluence
  arrangement and shared travel. Peak, width and timing are separate outcomes.

An outlet-only comparison can support a conditional association with river form;
it cannot by itself identify branch transport as the cause. More events at one
outlet do not create additional independent whole-network forms.

## Completion and stopping point

This version ends with a reproducible evidence summary, an actual source/data
availability audit and a scientific decision. No model training, new graph
architecture, reclassification based on DOC, or alteration of historical
experiments is included. The scientific target is a repeatable structural
contribution to concentration, variability or event response across independent
networks; a universal ordering of every form is not required.

If the available archives cannot supply that comparison, state the concrete
missing observations and finish the current-data analysis. New data, rather
than another rearrangement of the same records, would be the next advance.
