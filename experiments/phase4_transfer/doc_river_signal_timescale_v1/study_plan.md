## Fixed evidence and comparisons

  cropped real gauge-to-receiver paths, area shares and original form classes.
- Repeat separately on the saved shortest-route definition. Do not merge
  populations or replace the original route results.
- Use every network and the fixed >=80% monitored-area subset. Give receivers

- All sources have equal marginal anomaly variance and exponential temporal

  test scores select those values. The correlation times are 0.025, 0.05, 0.1,
  0.25, 0.5, 1, 2, 4 and 8 times the network's mean nominal travel time.
- Compare actual path differences with aligned arrivals. Both preserve the
  original area-weighted mean path time and use exactly the same source process.
- A common, unit-gain exponential kernel allocates 0, 0.25, 0.5 or 1 of the
  mapped shared-corridor nominal time to dispersion, replacing that amount of
  deterministic translation. Every individual path mean remains unchanged.
  This imposed kernel is not a measured lake residence time or DOC removal.
- Main working point: correlation time 0.5, coherence 0.5, allocation 0.5.
  Retain the complete grid and both coverage populations.

For input covariance exp(-|lag|/T), the covariance after one shared kernel of
mean tau is

`K(d) = [T^2 exp(-|d|/T) - T tau exp(-|d|/tau)] / (T^2 - tau^2)`.

Use its continuous tau=T and tau=0 limits. Compare the outlet variance with the
variance of the **same instantaneous area mixture**, not a single source.
Separate delay smoothing, additional shared-memory smoothing and their
interaction. Source independence should remove the delay-only variance effect;
a shared translation should not change any stationary variance.
