# M2 learned-lag interim review

The matched-budget learned-lag arm is complete (3 analytes x 2 holdout
families x 3 seeds). The comparison uses the same station-month test cells as
the M1 and H2X-T products; the paired table is generated by
`scripts/compare_graph_mechanisms.py`.

| analyte | holdout | learned lag MAE | M1 MAE | learned minus M1 |
|---|---|---:|---:|---:|
| DOC | temporal | 1.364 | 1.143 | +0.221 |
| DOC | spatial | 3.791 | 3.490 | +0.301 |
| pH | temporal | 0.261 | 0.272 | -0.010 |
| pH | spatial | 0.293 | 0.280 | +0.012 |
| specific conductance | temporal | 210.82 | 190.97 | +19.85 |
| specific conductance | spatial | 527.69 | 489.47 | +38.22 |

These numbers are a mechanism result, not a claim that the lag architecture is
universally worse. They show that the learned lag gate does not recover the
missing performance in this dataset. The fixed, same-month and no-message
controls are being run to separate a lag-parameterization problem from a
message-value problem.
