# DOC mechanisms on the river footprint actually monitored

## Question

Which parts of a measured river connection organize DOC mixing and timing:
the independent tributary branches or their common downstream trunk?
Preserve the three whole-network outline classes and the previous signal study.
This follow-up has seen their results and is exploratory, not an independent
confirmation or external validation.

## Matched structural footprint

Keep every one of the previous 59 eligible branch pairs, 22 receivers and 11
shared monitoring systems, with the identical 3,026 connection-month records.
Use primary downstream NHDPlus routes between the actual station measures.
Partition each pair into independent branch A, branch B and a single common
trunk. Save every touched COMID, partial length and storage status. Recalculate
endpoint and junction distances and compare with the original inventory.

Measure branch balance (area proxy), independent-branch path CV, total-path CV,
common-trunk share of the area-weighted mean path, and branch/trunk storage
fractions. These are measurements of the sampled corridor, not a replacement
for complete upstream-network shape. Keep whole-network descriptors alongside
them. Source coverage records how much of the outlet drainage is monitored.

Choose four map examples from geometry alone: lower/higher branch CV crossed
with lower/higher common-trunk share, using their median cuts and nearest
geometric median in each occupied quadrant. These are display examples,
not four new natural morphology classes. Maps use cached actual channel geometry
and linear-reference station positions; no DOC outcome selects an example.

## Controlled structural operations

Both sources receive the same Gaussian concentration pulse, SD 0.15, with
constant positive area-proxy flow shares summing to one. Normalize actual total
paths to weighted mean one once, then compare:

1. Actual independent branches plus the measured common trunk.
2. Equal independent branches at the same weighted mean, common trunk unchanged.
3. Original independent branches with the common trunk removed: identical branch
   separation and flow weights, different average delay.

Use a centroid-centered common evaluation grid so a shared translation has the
same pulse shape numerically. Preserve total anomaly mass and steady signal.
Under a common constant-velocity scenario, a shared trunk supplies translation,
while unequal branches supply relative arrival. Reservoir residence and
processing are recorded as possible additional operations, not fitted rates.
The relative time axis is not measured days or an inferred hydraulic velocity.

## Actual DOC on the same footprint

Reuse the native and log1p variability outcomes from the previous fixed calendar
adjustment. Aggregate connections within receiver before structural associations.
Report all six exploratory associations: each of branch balance, independent
branch CV and common-trunk fraction against native and log1p outlet/mixture
log-SD ratio. Include the other two structural terms, log mean path and source
coverage as controls. Use 5,000 whole monitoring-system bootstrap draws and
leave-system influence, retaining rank-deficient draw counts and leverage.

Separate three pieces of the existing current/previous source interpolation:
shared-trunk delay, equal independent-branch delay, and unequal-branch arrival.
All use the prior geometric scale and saved held-system mean-delay calibrators;
do not refit, scan a lag grid or choose a winner from receiver DOC. Report exact
input decomposition, paired MAE/log-MAE differences, signed bias and Q90 MAE.
Q90 thresholds remain those in the saved outer-training states. Source values
are legitimate known inputs in this diagnostic; it is not a no-water-quality K0
reconstruction task. Hidden receiver labels score predictions only.

Report every comparison against the complete saved mean-delay model, not a
weaker substitute. The common-only sensitivity is a mechanism comparison under
the same coefficients, not a newly trained best-performance model. Retain
receiver-equal summaries, system-bootstrap intervals and monitoring coverage.

## Deliverables

Real monitored footprint maps, controlled pulse comparisons, measured DOC and
paired prediction sensitivities, replayable records and a research decision.
Explain how matched corridor structure differs from whole-network shape, and
identify the operation worth incorporating in a future graph model.
