# Regional residual product

This directory is a post-processing product of the frozen five-seed source-pool-40 ExtraTrees spatial transfer runs. It provides an E3 outer-test table with all 2,531 cells, a fixed 2,316-cell paired query table, the K curve, station-clustered bootstrap intervals and a publication-ready figure. Support labels are used only to compute the station mean residual; support rows are marked and excluded from paired-query metrics. No model is retrained.
