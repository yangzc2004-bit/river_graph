# Whole-network tributary entry layout

An analysis of where lateral tributaries join the mainstem and which part of
the routed outlet-arrival variance originates within tributaries versus between
their mean arrival times. Original whole-network classes and matched pairs are
retained. Read `study_plan.md` for definitions and `research_decision.md` for the
results and research interpretation.

## Reproduce

```bash
uv run python scripts/analyze_doc_river_junction_layout_v1.py --bootstrap-draws 5000
uv run python scripts/plot_doc_river_junction_layout_v1.py
uv run python scripts/plot_doc_river_junction_layout_v1.py --chinese
uv run python scripts/verify_doc_river_junction_layout_v1.py --full

# Separately retain the original geometric mainstem at real mapped links.
uv run python scripts/analyze_doc_river_junction_layout_v1.py --bootstrap-draws 5000 --geometric-mainstem
uv run python scripts/plot_doc_river_junction_layout_v1.py --geometric-mainstem
uv run python scripts/plot_doc_river_junction_layout_v1.py --geometric-mainstem --chinese
uv run python scripts/verify_doc_river_junction_layout_v1.py --geometric-mainstem --full
```

The existing local NHDPlus attribute table, saved routing, complete mapped
network membership, basin boundaries and flowline SQLite cache are required.
Original data sources are the preceding `doc_river_morphology_effect_v1`,
`doc_river_storage_placement_v1`, and `doc_river_planform_typology_v1` products.
No public mixing observations, new field DOC measurements or neural training
are generated by this analysis.

## Products

- `station_junction_layout.csv`: one row per original receiving network;
  geometric descriptors, variance budgets and copied monthly DOC context.
- `tributary_units.parquet`: non-overlapping lateral subtrees and mainstem-local
  catchments, unique incremental areas and unit arrival moments.
- `entry_junctions.csv` / `route_mainstems.csv`: exact routed topology for replay.
- `arrival_scenarios.csv`: conservative identical-input timing interventions.
- `fine_resolution_scenarios.csv` / `numerical_sensitivity.csv`: discretization
  sensitivity, not additional observational replications.
- `form_summary.csv` / `matched_form_contrasts.csv` / `matched_pair_evidence.csv`:
  class distributions and original 22-pair HUC4 bootstrap contrasts, tagged by
  evidence type.
- `representatives.csv` / `representative_curves.parquet`: the original three
  geometry-selected examples and their controlled response curves.
- `figures/`: actual whole-network maps, entry positions and response diagnostics,
  plus class and matched-comparison figures in English and Chinese.

Entry positions are relative distances, not calendar time. Catchment area is a
source-flow proxy. Passive spreading preserves integrated anomaly and steady
concentration. The original geometric mainstem may follow alternate channels;
this version saves a contiguous mainstem on the existing single-route tree and
reports its differences without changing the original class labels.

The `original_mainstem_sensitivity/` subtree retains the same products for a
second route definition. It follows the original mapped trunk and changes only
trunk successors, with every change checked against a real primary/minor link.
This sensitivity was added after the first shortest-route results were seen,
because their derived mainstems had limited overlap with the geometric trunks.
Both analyses are kept; neither represents measured branching discharge splits.
