# 历史预测的有边界诊断（A3，2026-09-12）

依据 `docs/execution_plan_20260912.md` 的 A3 阶段。**本轮没有执行任何训练**：只读取 A0 白名单放行的已存预测。

## 1. 输入与口径

- 白名单来源：`experiments/frozen_results/prediction_manifest_20260912.json`（A0 冻结）。
- 实际读取 **154** 个文件 = `experiments/predictions/` 的 83 个（排除 1 个冲突文件、1 个 manifest 中标注为零覆盖）+ `experiments/predictions_historical/` 的 70 个（历史批次）。
- 只使用**合法 test 单元**。测试单元边界取自 mask 的 `test` 平坦索引，再按 `(station, month)` 与 parquet 行匹配；A0 已抽检确认 parquet 的 `split=="test"` 与 mask test 集完全一致。
- 聚合同时给出**逐站等权**（`*_station_equal`）与**逐单元加权**（`*_cell_weighted`）。
- R² 只在单站 test 单元 ≥ 10 时计算，否则记 NaN。

## 2. 逐站与逐区域

- 逐站明细：`predictions_per_station_20260912.csv`（62,325 行 = 154 次预测 × 各次参与 test 的站点）。
- 区域（HUC2）：`predictions_by_huc2_20260912.csv`。
- 图角色与上游度：`predictions_by_graph_role_20260912.csv`、`predictions_by_upstream_degree_20260912.csv`。

**区域集中**：E3 场景下历史 H2X 的逐单元加权 MAE 在 **HUC2=6（ Tennessee / 下密西西比支流）最高，为 3.547**，明显高于其他主要区域（HUC2=7 为 1.149、3 为 1.074、5 为 1.423、10 为 2.035）。HUC2=6 也是站点 06438000 所在区域（见 §6），两者一致指向同一批高 DOC 的南方站点是误差主要来源。

## 3. 图角色：命名必须准确

`upstream_degree == 0` 在本报告中一律称为「**监测图中无上游监测邻居**」。这**不等于**真实水文源头——那需要河网属性核验（`reach_attributes.csv` / NHDPlus），本轮不做。图注与正文必须使用同一个措辞。

历史 H2X 逐单元加权 MAE（`no_upstream` 对 `has_upstream`）：

| 场景 | 无上游邻居 | 有上游邻居 | 差值 |
|---|---:|---:|---:|
| E1 | 1.684 | 1.175 | +0.510 |
| E1_r40 | 1.665 | 1.200 | +0.465 |
| E1_r60 | 1.797 | 1.277 | +0.520 |
| E2a | 1.077 | 0.872 | +0.205 |
| E2b | 1.201 | 0.961 | +0.240 |
| E3 | 1.952 | 1.586 | +0.366 |

**在所有场景中，无上游监测邻居的站点误差都更高**，且这一模式在基线模型（B0 站点均值、G0 随机图）上同样存在——说明它主要反映**这批站点本身的 DOC 更难预测**，而不是图模型特有的缺陷。G0 随机图在这些站点上的误差最大（E1 达 2.545），说明有意义的图结构确实改善了它们，但改善并未消除差距。

## 4. 极端值：误差高度集中

`predictions_extreme_concentration_20260912.csv` 按每次预测的 test 集计算 **DOC ≥ 99 分位**的单元对平方误差的贡献：

- **全部 154 次预测的中位贡献为 74.2%**——即 1% 的高 DOC 单元贡献了约 74% 的平方误差。
- 最极端的是 **E3 seed43：41 个单元（占 1.02%）贡献了 95.6% 的平方误差**，H2X 的 MAE 从 2.119（全量）降到 1.582（剔除 top 1%）。

这正是 `evaluate.metrics` 同时给出 log 空间指标的原因：mg/L 空间的 RMSE 被极少数高值主导。**任何以 RMSE 为主的模型比较都必须同时给出 log 空间或剔除极端值的版本**，不能只报 RMSE。

**E3 seed42/43/44 与区域、高 DOC 单元的误差贡献**均来自**历史批次**（`experiments/predictions/`），不是新五种子结果。

## 5. 站点类型：描述性敏感性，不是 ST-only 验证

`predictions_station_type_split_20260912.csv`。571 个节点中 **556 个**能匹配到站点类型，其中 **427 个为 ST**、129 个为其他类型。

历史 H2X 逐单元加权 MAE：

| 场景 | ST | other |
|---|---:|---:|
| E1 | 1.516 | 0.854 |
| E2a | 0.974 | 0.560 |
| E2b | 1.089 | 0.629 |
| E3 | 1.810 | 1.309 |

**ST 站点误差系统性高于其他类型**，但这一顺序在 **B0 站点均值基线**上同样成立（E1：1.587 对 0.816），G0 河网图亦然。因此：

- 这主要说明 ST 站点（河流，DOC 变幅大、含高值）本身更难，**不是**图模型对 ST 失效的证据。
- 模型仍在**混合数据**上训练，本表**不能**冒充 ST-only 独立训练验证。真正的 ST 核心版本需要重新构图与划分（B1/B2），本轮不做。

## 6. 站点 06438000

`predictions_station_06438000_20260912.csv`（111 行，11 个模型 × 各 mask）。

- 该站位于 **HUC2=6**，`site_tp_cd = ST`，`upstream_degree = 1`（监测图中有上游邻居）。
- 其 test 期真实值的**平均为 63.05 mg/L、最大 134.7 mg/L**，中位数 58.2 mg/L——明显高于全局典型量级。
- 所有模型都严重低估：例如 B0 站点均值在 `e1_r20_seed42` 上 `mean_true=134.7` 而 `mean_pred=13.2`，MAE 达 129.0。

**结论边界**：数据里确实存在有效的高值，且模型无法重建它。但**相关性不足以确认成因**（土地利用、采样方法或 1970 年代区域性高 DOC 期）——现有审计（`experiments/analysis/`）也未能用可用协变量解释它。因此本报告只陈述「该站高值有效、误差极大、成因未定」，**不主张**任何具体成因。

## 7. 置信区间（样本层，不能替代训练种子分析）

`predictions_station_bootstrap_20260912.csv`：按**站点**重采样（2000 次）的逐单元加权区间。

| 模型 | 场景 | MAE 点估计 | MAE 95% 区间 |
|---|---|---:|---|
| H2X | E2a | 0.956 | [0.816, 1.105] |
| H2X | E2b | 1.060 | [0.899, 1.232] |
| H2X | E3 | 1.744 | [1.513, 2.058] |
| H2 | E2a | 1.080 | [0.915, 1.253] |
| G0 river | E1 | 1.671 | [1.565, 1.802] |

**重要限定**：

- 这是**固定历史模型的样本层区间**，反映「哪些站点被划入 test」，**不是**训练随机性，也不能替代缺失的五种子分析（A2 的 `*_sd_seeds` 才是训练随机性）。
- 区间较宽（如 E3 的 MAE 区间跨约 0.55），**因此不能**用两个模型区间不重叠来论证模型差异。

## 8. 明确无法开展（列缺口，不用代理补齐）

`predictions_five_seed_gap_20260912.csv` 记录 H1/H2/H2X 的三项缺口：

| 模型 | 五种子逐样本预测 | 历史逐样本预测 | 多种子指标 | 比较可否开展 |
|---|---:|---:|---:|---|
| H1 | 0 | 14 | 8 | **否** |
| H2 | 0 | 14 | 8 | **否** |
| H2X | 0 | 14 | 8 | **否** |

因此本轮**没有**：五种子预测集成、五种子残差地图、五种子逐站区间；也**没有**把历史单次预测与五种子指标做逐站对比（两者不是同一批次，混比会制造虚假精度）。

其他限制：

- **Kriging 覆盖率不足**：`e2a_strict` 覆盖率为 **0%**（该行 n=0、MAE/R² 为 NaN），`e2b_partial` 为 95.1%，E1 系列 98.0–99.8%。**不同有效样本范围下不直接比较误差大小**；相关表格已并列 n 与覆盖率。
- **不引用生态分组排名**：`H2X_{hydro,landcover,climate,soil_topo}_river` 的 16 行历史指标受 `env_groups` 取列错误影响，本报告未使用。历史 H2E/H2X 全特征比较保持描述性。
- **15 个站点没有类型信息**：类型表中 571 站仅 556 站可匹配（ST 427 个），其余 15 站在 §5 中记为 NaN，不推断填补。
